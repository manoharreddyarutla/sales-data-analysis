Sales Data Analysis
 Project Overview

This project analyzes sales data using Python and Pandas to identify total sales, average sales, and sales performance by product.

Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

Project Files
- `sales_data.csv` - Sales dataset
- `sales_analysis.py` - Python analysis script
- `sales_by_product.png` - Sales visualization

 Analysis Performed

- Loaded sales data from CSV
- Calculated total sales
- Calculated average sales
- Analyzed sales by product
- Created a bar chart for product-wise sales

Key Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Aggregation
- Data Visualization
- Python Programming
